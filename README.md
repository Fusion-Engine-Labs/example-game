# Sandbox game

Gameplay builds as a native library using `fusion-sdk`. Built-in component
schemas/types come from the SDK; `game_components.zig` declares only game types.
The editor has no build dependency on this project.

The game builds against the sibling `../fusion-sdk` checkout, so it always
matches the SDK the local runtime and editor use. From this directory, build
the game in Debug:

```sh
zig build -Doptimize=Debug
zig build test -Doptimize=Debug
```

## Arena

The default scene, `scenes/arena.scene.json`, is a small first-person target
range. Press Play in the editor, then click the viewport to capture the
mouse. Escape gives it back, as do Pause, Stop, and switching windows.

| Input | Action |
| --- | --- |
| Click | Capture the mouse (this click does not fire) |
| Mouse | Look |
| W A S D | Move |
| Shift | Sprint |
| Space | Jump |
| Arrow keys | Look without the mouse |
| Left mouse (hold) | Fire |
| Escape | Release the mouse |

Twelve targets strafe, bob, spin, and hide on pillars and the overlook.
Destroyed targets respawn after a few seconds. Kills less than 2.5 s apart
multiply their points (up to x5), and destroying every target before any
respawns is a range clear (+1000). Score, accuracy, and a session summary
are logged to the Console.

Movement is acceleration-based with buffered jumps, coyote time, and stair
stepping (ledges up to 0.45 m). Collision is axis-aligned boxes. Bolts are
swept each step so they cannot tunnel through thin walls, and they converge
on whatever the crosshair is over.

### Components

| Component | Put it on | Purpose |
| --- | --- | --- |
| First Person Controller | The active camera | Movement, jumping, body size, eye height, mouse sensitivity, head bob, sprint FOV |
| Blaster | Same entity | Fire rate, bolt speed, damage, muzzle position, and the bolt, spark, and muzzle flash meshes |
| Box Collider | Any static solid | Blocks the player and bolts (rotation is ignored) |
| Target | Anything with a mesh | Health, points, motion, respawn delay |
| View Model | Gun, crosshair, hit marker | Locks the entity to the camera with sway and recoil |

Runtime state (`FirstPersonState`, `BlasterState`, `TargetState`,
`Projectile`, `Particle`) is added during play and never authored.

### Assets

Every mesh, texture, and material the arena uses, plus the scene itself, is
generated by a dependency-free script. Edit the script and re-run it rather
than editing its outputs:

```sh
python3 tools/generate_arena.py
```

Asset and entity IDs are derived deterministically, so re-running keeps
scene references valid. Most materials are generated by the asset cooker from
the glTF. The script writes a handwritten `.zamat` only where glTF cannot
express a setting: the HUD's no-depth-test overlay and the grid's anisotropic
filtering.

## Showcase scenes

`scenes/backpack.scene.json`, `main.scene.json`, and `multi_mesh.scene.json`
are renderer showcases. Entities with Keyboard Movement move with WASD or
the arrows. Add a Projectile Launcher to an entity with a mesh and press Space
while playing to fire copies of it.
